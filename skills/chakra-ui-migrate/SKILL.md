> **Source:** `skills/chakra-ui-migrate/SKILL.md` (upstream)

> **Install:** `npx skills add https://github.com/chakra-ui/chakra-ui/tree/main/skills/chakra-ui-migrate`

## Purpose

Migrate existing UI code to **Chakra UI v3** idioms — prop mapping, codemod guidance, and token migration.

## When to use

- Upgrading from Chakra v2 → v3
- Converting Tailwind / shadcn / raw JSX to Chakra primitives
- Aligning legacy style props to `recipes` / `slotRecipes` / `semanticTokens`

## Install

```bash
npx skills add https://github.com/chakra-ui/chakra-ui/tree/main/skills/chakra-ui-migrate
```

## What this skill provides to Blueprint

When installed, Blueprint injects:

```md
- Chakra UI — Migrate [chakra-ui-migrate] — Migrate existing UI code to Chakra UI v3 idioms and props. (package: @chakra-ui/react | npx skills add https://github.com/chakra-ui/chakra-ui/tree/main/skills/chakra-ui-migrate)
```

Generated codemods/docs must follow v3 migration rules.
