# Chakra UI Refactor Skill

> **Source:** `skills/chakra-ui-refactor/SKILL.md` (upstream)
> **Upstream:** https://github.com/chakra-ui/chakra-ui/tree/main/skills/chakra-ui-refactor
> **Install:** `npx skills add https://github.com/chakra-ui/chakra-ui/tree/main/skills/chakra-ui-refactor`

## Purpose

Refactor and clean up Chakra UI code — DRY style props, extract recipes, improve composition and prop hygiene.

## When to use

- Cleaning up verbose `css` / style prop duplication
- Extracting repeated patterns into `cva` recipes / `sva` slotRecipes
- Improving composition (`asChild`, `as`, `Slot`) and accessibility

## Install

```bash
npx skills add https://github.com/chakra-ui/chakra-ui/tree/main/skills/chakra-ui-refactor
```

## What this skill provides to Blueprint

When installed, Blueprint injects:

```md
- Chakra UI — Refactor [chakra-ui-refactor] — Refactor and clean up Chakra UI code — DRY up style props, recipes and composition. (package: @chakra-ui/react | npx skills add https://github.com/chakra-ui/chakra-ui/tree/main/skills/chakra-ui-refactor)
```

Generated refactors must preserve a11y and use Chakra composition APIs.
